# Smart Student Profile Processor

## Description
This project is a C# Week 1 assignment for CTU Training Solutions.

The system captures student information, validates input, calculates readiness status, and displays results using:
- Console Application
- Windows Forms Application

## Features
- Student name, age, and assessment score input
- Input validation
- Readiness calculation
- Windows Forms user interface

## Technologies Used
- C#
- .NET Framework
- Windows Forms
- Visual Studio
